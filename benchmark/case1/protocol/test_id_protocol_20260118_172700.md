# 7. Computational Workflow

## Goal:
Systematically compute the zero-bias transmission at the mid-gap energy for a grid of (θ, ϕ) conformations of biphenyl diamine to generate a 2D transmission map, and test cos²(θ) behavior.

## Step 1. Create directories
1. Create a project root:

   ```bash
   mkdir bda_scan
   cd bda_scan
   ```

2. Create a directory for all conformations:

   ```bash
   mkdir structures
   mkdir results
   ```
3. Place all generated conformations into `structures/`:

   ```
   bda_scan/
     structures/
       theta_00_phi_00.xyz
       theta_00_phi_10.xyz
       ...
       theta_90_phi_180.xyz
   ```

## Step 2. Run Calculation
A batch script should be used to run the `L1_XTB` module on every `.xyz` file in the directory. The anchor atom indices `[L_idx]` and `[R_idx]` for the two Nitrogen atoms must be predetermined.

```bash
#!/bin/bash

# User-defined parameters (keep fixed across all structures)
LEFT_N_IDX= [N_L]   # replace with actual left N index
RIGHT_N_IDX=[N_R]   # replace with actual right N index
COUPLING=1.0        # Γ (eV), fixed for all
ERANGE=4.0          # eV, symmetric around E_F
ENUM=400           # number of energy points

STRUCT_DIR=structures
RESULT_DIR=results

mkdir -p ${RESULT_DIR}

for xyz in ${STRUCT_DIR}/*.xyz; do
    fname=$(basename ${xyz} .xyz)
    outdir=${RESULT_DIR}/${fname}
    mkdir -p ${outdir}
    cp ${xyz} ${outdir}/

    cd ${outdir}

    # Run L1_XTB
    L1_XTB -f ${fname}.xyz \
           -L ${LEFT_N_IDX} \
           -R ${RIGHT_N_IDX} \
           -C ${COUPLING} \
           -m 1 \
           --Erange ${ERANGE} \
           --Enum ${ENUM}

    cd - > /dev/null
done
```
