# 1. Query Summary
The user wants to compute and compare the current-voltage (I-V) characteristics and transmission functions for two single-molecule junctions: a symmetric tetraphenyl dithiolate junction and an asymmetric dipyrimidinyl-diphenyl dithiolate junction. The goal is to computationally reproduce the experimental observation that the symmetric junction exhibits a symmetric I-V curve, while the asymmetric junction shows significant rectification, with a rectification ratio of approximately a few at a bias of around 1.5 V.

# 2. Computational Objectives
1.  Compute the I-V curves for both the symmetric and asymmetric molecular junctions for a bias voltage range covering at least -1.5 V to +1.5 V.
2.  Calculate the bias-dependent transmission spectra, T(E,V), for both systems.
3.  Compare the I-V curves to demonstrate the symmetric response of the tetraphenyl junction and the rectifying behavior of the dipyrimidinyl-diphenyl junction.
4.  Calculate the rectification ratio for the asymmetric junction at |V| ≈ 1.5 V.

# 7. Computational Workflow

## Goal:
Compute and compare the I-V curves for the symmetric (TP) and asymmetric (DPDP) junctions to analyze the rectification behavior.

## Step 1. Create directories and Prepare Inputs
Create the directory structure and place the corresponding user-created junction `.xyz` files inside:
```
/TP_junction/junction_trimer_TP.xyz
/DPDP_junction/junction_trimer_DPDP.xyz
```

## Step 2. Convert to POSCAR
Run the `xyz2POSCAR.py` conversion script in *each* of the two directories.

1.  **For the `TP_junction` system:**
    ```bash
    cd TP_junction
    # Copy xyz2POSCAR.py from [MST_root]/share/ into this directory
    # Edit xyz2POSCAR.py: set xyz_filename = 'junction_trimer_TP.xyz'
    python xyz2POSCAR.py
    cd ..
    ```
2.  **For the `DPDP_junction` system:**
    ```bash
    cd DPDP_junction
    # Copy and edit xyz2POSCAR.py: set xyz_filename = 'junction_trimer_DPDP.xyz'
    python xyz2POSCAR.py
    cd ..
    ```
    This generates `POSCAR` and `EM_atom.txt` in each directory.

## Step 3. Measure Extended Molecule Length
For both systems, open the `junction_trimer_....xyz` file in a visualization software (e.g., VESTA) and measure the distance in Ångstroms along the transport (z) axis between the outermost atoms of the extended molecule. Record these two values (e.g., `L_TP` and `L_DPDP`).

## Step 4. Run Finite-Bias Calculation
Use the `current_parallel.py` script to run the I-V calculation for each system.

1.  **For the `TP_junction` system:**
    -   Copy `current_parallel.py` from `[MST_root]/share/` into the `TP_junction/` directory.
    -   Edit `current_parallel.py` and set the parameters in the `main` function:
        -   `poscar_file`: `"POSCAR"`
        -   `Length`: The measured length for the TP system (e.g., `22.5`).
        -   `input_energy_range`: `2.0`
        -   `input_energy_interval`: `0.01`
        -   `electric_field_range`: To reach ~1.5V, a field of ~0.0013 a.u. is needed for a 22.5 Å molecule. Use a range like `np.arange(-0.0014, 0.0015, 0.0001)`.
        -   `max_workers`: `4` (adjust based on available RAM).
    -   Run the script:
        ```bash
        cd TP_junction
        python current_parallel.py
        cd ..
        ```

2.  **For the `DPDP_junction` system:**
    -   Repeat the process in the `DPDP_junction/` directory, using the measured length for the DPDP system to set the `Length` and `electric_field_range` variables accordingly.
    -   Run the script:
        ```bash
        cd DPDP_junction
        python current_parallel.py
        cd ..
        ```

## Step 5. Post-processing and Analysis
The script will automatically generate a `voltage_current.txt` file in each directory, containing the final I–V data. 

1.  Collect the `voltage_current.txt` files from both the `TP_junction/` and `DPDP_junction/` directories, and plot the I–V curves on the same graph.

2.  Analyze the I–V curves:
    -   Verify that the I–V curve for the TP system is nearly symmetric around the origin (i.e., I(V) ≈ -I(-V)).
    -   Verify that the I–V curve for the DPDP system is clearly asymmetric, indicating rectification.
    -   From the `voltage_current.txt` data for the DPDP system, determine the current values at bias points closest to V ≈ +1.5 V and V ≈ -1.5 V, and calculate the rectification ratio as `RR = |I(+1.5 V) / I(-1.5 V)|`, confirming that it is on the order of a few.

3.  For each junction, identify a representative pair of opposite bias points at comparable magnitude in the high-bias regime (preferably those closest to +1.5 V and -1.5 V, or the nearest available values from the field scan), and extract the corresponding transmission spectra `T(E, V)` for both positive and negative bias.

4.  Plot and compare the forward- and reverse-bias transmission spectra for each junction on the same energy axis within the transport window:
    -   For the TP junction, verify that the transmission spectra under positive and negative bias are similar, consistent with its nearly symmetric I–V response.
    -   For the DPDP junction, verify that the transmission spectra under opposite bias polarities differ significantly, consistent with its rectifying behavior.
    -   At a representative pair of opposite bias points where rectification is clearly observed (preferably near +1.5 and -1.5 V), plot and compare the corresponding transmission spectra for each junction on the same energy axis, with particular attention to differences within the corresponding bias window.
